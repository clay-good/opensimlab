# Module proposals

A module joins the catalog in four steps, and each step is checked by
`scripts/module-proposals.ts` (`tests/unit/module-proposals.test.ts`).

| Status | Earned when |
| --- | --- |
| `proposed` | The document exists. Nothing is promised. |
| `breadth-test-passed` | Every section below is written, and at least eight scenario proposals each name their **Actions**, **Choices**, **Consequences**, and **Debrief**. A proposal that reads as a calculator, lookup, or checklist answer does not count. |
| `planned` | The breadth test passed and the first evidence briefs exist. Only now may the landing page show the module as planned. |
| `declined` | A `Declined because:` line says why. The document stays. |

Required sections: Learner roles and setting, Scenario proposals, Shared capabilities,
Formulary, Review domains, Negative-transfer analysis, Regional variation. A section that says
"Not yet written" counts as missing.

The ratified catalog of 256 is a floor, not a ceiling. Nothing here commits to a module or a
date.
